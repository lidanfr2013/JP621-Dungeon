Одно задание, реализованное с нуля на Python — и pull request с ним.

Ниже — два варианта финального проекта курса. Берите один (можно и оба), пишите консольное приложение с полноценным ООП и JSON-хранилищем, сдавайте через PR в репозиторий курса.

Терравариум

Симулятор виртуальных питомцев в терминале

Заводите питомцев трёх видов, кормите, укладывайте спать и лечите — характеристики меняются даже пока приложение закрыто, время «доначисляется» при следующем запуске.

Открыть задание
Минимум 3 вида, JSON вместо базы, время идёт даже без запуска

Подземелье

Текстовый квест-движок с пошаговой боевой системой

Комнаты, инвентарь, диалоги с NPC и бой с противниками. Мир игры описан в JSON как контент, прогресс игрока — в отдельном JSON как сохранение.

Открыть задание
Не меньше 5 комнат, отдельные файлы для мира и сохранения

Оба задания сдаются одинаково — fork, ветка, коммиты, pull request. Дедлайн: 25 сентября 2026 года.
