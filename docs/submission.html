Как сдавать работу

Порядок один и тот же для обоих заданий — отличается только заголовок pull request. Работа сдаётся через GitHub: fork, ветка, коммиты, PR в репозиторий курса.

Дедлайн: 25 сентября 2026 года. Pull request должен быть открыт до этой даты — изменения после дедлайна не учитываются, если не указано иное.

Сделайте fork репозитория

Форкните JP621-Final-Project к себе на GitHub.

Склонируйте форк локально

git clone <ссылка-на-форк>

Работайте в отдельной ветке

Например, feature/<github-логин> или submit/<фамилия> — либо прямо в main своего форка.

Коммитьте регулярно

С понятными сообщениями — история коммитов учитывается при проверке как отражение процесса работы, а не только финальный результат.

Если репозиторий общий для группы

Размещайте проект в отдельной папке с именем или группой — структура папки описана в README репозитория.

Приложите README

Инструкция запуска и краткое описание проекта — обязательны.

Откройте Pull Request

Из своего форка в исходный (upstream) репозиторий, когда проект готов к проверке.

Назовите PR правильно

Фамилия Имя — Название проекта, например Иванов Иван — Терравариум.

Опишите, что реализовано

В описании PR — что сделано и какие есть известные ограничения или недоделанные пункты.

Успейте до дедлайна

Работа считается сданной с момента открытия PR до дедлайна — 25 сентября 2026 года; изменения после дедлайна не учитываются, если не указано иное.

Дорабатывайте в том же PR

Проверка и обсуждение идут в комментариях к PR; доработки — новыми коммитами в ту же ветку, без создания нового PR.

Заголовок PR зависит от проекта:
  • Терравариум — Фамилия Имя — Терравариум
  • Подземелье — Фамилия Имя — Подземелье
